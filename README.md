## ✨ Features

* **Legacy & Modern Device Support:** Universal ES5/XHR compatibility with progressive feature detection.
* **Smart Markdown & Math:** Renders Markdown formatting and dynamically loads KaTeX for LaTeX equations on supported browsers.
* **Responsive Touch Interface:** Mobile drawer navigation with auto-expanding input and virtual viewport handling.
* **Serverless Backend:** Hosted on Vercel's global edge network for low latency and zero server-sleep limits.
* **Built-in Rate Limiting:** Spam protection cooldown timers to prevent API request exhaustion.

## 💻 Installation & App Setup

This AI is hosted in the cloud and is not intended to be run locally. You can install it as a standalone app across your devices:

### On Android (APK / Web)

* **Dedicated Android App (Android 5.0+):**
  1. Head over to the [GitHub Releases](https://github.com/techsavvyguy456/techsavvy-ai/releases) page.
  2. Download the latest `.apk` file from the **Assets** section.
  3. Open the APK on your device, enable **Install from Unknown Sources** if prompted, and tap **Install**.
* **Web App (All Android Versions):** Open [techsavvy-ai.vercel.app](https://techsavvy-ai.vercel.app) in your browser, tap the menu (⋮), and select **Add to Home screen**.

### On Desktop (Google Chrome / Microsoft Edge)

1. Open [techsavvy-ai.vercel.app](https://techsavvy-ai.vercel.app) in your browser.
2. Click the **three dots menu** (⋮) in the top-right corner.
3. Select **Save and share** (or **More Tools**) and click **Install page as app** (or **Install this site as an app**).
4. Name your app **TECHSAVVY AI** and click **Install** to add it to your desktop and Start Menu.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (with legacy WebKit prefixes), Vanilla JavaScript (ES5 fallback + dynamic CDN loading)
* **Backend:** Node.js, Express, Vercel Serverless Functions
* **AI Model:** Mistral AI (`mistral-small-latest`)
* **Libraries:** `marked` (Markdown), `KaTeX` (LaTeX typesetting)
